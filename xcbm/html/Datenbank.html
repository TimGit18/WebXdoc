Datenbank

Die Datenbank ist die physische Implementierung des logischen Datenmodells. Dabei wird idealerweise jeder Entität und jeder Beziehung eine Tabelle zugeordnet. Aus Performance-Gründen wird die Datenbank oft nicht normalisiert abgebildet, sondern es wird mit Datensichten oder denormalisierten Tabellen gearbeitet, dies ist aber bei kleinen Datenbanken wie der CBM-Datenbank nicht notwendig. Im Grunde könnte man auch in dieser Anwendungsdomäne auch ohne Datenbank areiten, jedoch ist sie hier aus didaktischen Gründen nützlich.

Implementierung

Das zugrundeliegende Relationale Datenbank-Managementsystem (RDBMS) ist ein SQL Server 2022 von Microsoft. Als Werkzeug zur Administration der Datenbank wird dasw SQL Server Management Studio verwendet.

Erstellung

Die Erstellung der Datenbank benötigt eine Administrator-Account. Mit folgendem Kommando wird die Datenbank CBM angelegt: 

                        create database CBM;

Tabelle Magazine

Die Tabelle Magazin ist die Implementierung der Entität Magazin. Sie wird mit dem folgenden Kommando in der Datenbank angelegt: 

                        
        create table CBM.dbo.Magazine (
          id integer not null,
          issue nvarchar(6) not null,
          primary key (id));

Query über alle drei Tabellen

Die folgende Query stellt einen Join über alle drei verknüpften Tabellen dar: 

                        
        select t1.issue,
               t2.ecokey,
               t2.moves,
               t2.eco_description,
               t3.cbm_eco_description
        from   CBM.dbo.Magazine t1,
               CBM.dbo.ECO t2,
               CBM.dbo.Magazine_ECO t3
        where  t1.id = t3.id_magazine
        and    t2.id = t3.id_eco
        order by t2.ecokey;

Dieser Abfrage selektiert alle Eröffnungsartikel mitsamt den dazugehörigen Eröffnungsschlüsseln und Magazinen sowie den dazugehörigen Beschreibungen und Zügen. Sortiert wird der Result Set am Ende nach den Eröffnungsschlüsseln wie in der folgenden Teilmenge dessen zeigt:
