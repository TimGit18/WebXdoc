Kommandozeilen-Werkzeuge

Um Anwendungen in Java zu entwickeln, werden Projekte und Entwicklungswerkzeuge benötigt. Der gewöhnliche Entwicklungszyklus besteht aus dem Editieren des Quellcodes, Kompilieren der Klassen, Testen der Anwendung, Auslieferung in die Laufzeitumgebung und Ausführung der Anwendung. Eine geeignete Projektstruktur unterstützt dieses Vorgehen und trennt die einzelnen Komponenten des Projekts nach Anwendungsbereichen. Bevor man sich mit komplexen und leistungsfähigen Werkzeugen wie Integrierten Entwicklungsumgebungen (IDEs) oder Build-Pipelines beschäftigt, macht es Sinn einfache Kommandozeilen-Werkzeuge zu kennen, um Basisaufgaben beherrschen zu können. Die einfachsten Kommandozeilen-Werkzeuge sind der Java-Compiler, der Java-Interpreter und der Java-Archiver. In diesem Dokument werden nur der Compiler und der Interpreter behandelt. Der Archiver erhält ein eigenes Dokument.

Pfad einbinden

Der einfachste Weg, um die Kommandozeilen-Werkzeuge in den Ausführungspfad des Betriebssystems einzubinden und damit direkt von der Kommandozeile aus aufzurufen, besteht darin, das Ausführungsverzeichnis bin des Java Development Kit in den Pfad einzubinden. Dazu erweitert man die Umgebungsvariable PATH des Betriebssystems um diesen Pfad. In Windows sieht diese Erweiterung folgendermaßen aus: 

                        set PATH=%PATH%;C:\Programme\Java\jdk21\bin

Java-Compiler

Der Java-Compiler javac ist das Kommandozeilen-Werkzeug für die Übersetzung von Java-Quellen. Er übersetzt die vom Entwickler editierte Quelldatei und erzeugt die Klassendatei. Die Quelldatei besitzt das Suffix .java und die Klassendatei das Suffix .class.

Der Aufruf lautet: 

                        javac [Optionen] Quelldateien

Quelldateien

Die Quelldateien besitzen immer die Endung .java. Es wird immer der komplette Pfad in Übereinstimmung mit der Paketstruktur übergeben.

Folgende Optionen sind möglich:

-cp [Pfad]

Mit dieser Option werden benutzerdefinierte Klassenpfade spezifiziert. Die Angabe von vollständigen Verzeichnissen oder einzelner Dateien wie .jar-Files ist möglich.

-d [Verzeichnis]

Mit dieser Option wird dem Compiler das Zielverzeichnis für die übersetzten Klassen angegeben. Es reicht die Angabe eines Oberverzeichnisses. Aus der Paketstruktur kann der Compiler die Unterverzeichnisse im Zielverzeichnis konstruieren.

-nowarn

Mit dieser werden Warnhinweise auf der Kommandozeilenausgabe unterdrückt. Die Quelldatei wird genauso übersetzt wie bei einem Compile ohne Warnung.

Java-Interpreter

Der Java-Interpreter java exekutiert ausführbare Hauptklassen oder Java-Archive. Der Aufruf im Fall einer ausführbaren Hauptklasse lautet: 

                        java [Optionen] Klasse [Argumente]

Der Aufruf für die Ausführung eines Archivs lautet: 

                        java [Optionen] -jar Archivdatei [Argumente]

Ausführung einer Klasse

Es kann nur die Hauptklasse einer Anwendung, die eine main-Methode enthält, ausgeführt werden. Die Klasse muss mit dem vollen Paketnamen qualifiziert werden.

Ausführung eines Archivs

Die Option -jar führt das im Archiv gekapselte Programm aus. Das Archiv ist die Quelle aller Anwendungsklassen. Alle anderen benutzerdefinierten Klassenpfade werden vom Interpreter beim Gebrauch dieser Option ignoriert. Bei Erstellung des Archivs muss eine Manifest-Datei mitgegeben werden, damit der Interpreter die Hauptklasse der Anwendung findet.

Folgende Optionen sind möglich:

-cp [Pfad]

Mit dieser Option werden benutzerdefinierte Klassenpfade spezifiziert. Die Angabe von vollständigen Verzeichnissen oder einzelner Dateien wie verschiedene Verzeichnisse und Dateien in einem Klassenpfad zu spezifizieren, müssen diese mit Amnführungsstrichen eingebunden und mit Semikola getrennt werden.

-Dname=value

Diese Option setzt eine Systemeigenschaft zur Laufzeit der Anwendung wie etwa Benutzername.
