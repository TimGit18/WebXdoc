Unterbereich-Referenz-Datei für xdoc

Dieser Text soll als Referenzdatei für den Dokumenten-Transformator in ein XML-Format fungieren. Zentrale Bedeutung haben die wesentlichen Struktur-Elemente von Textdateien (Listen, Tabellen, Bild-Referenzen, Code und Sequenzen). Und so weiter.

Listenstrukturen

Dieser Abschnitt beinhaltet Listenstrukturen. Zunächst eine nummerierte Liste, anschließend eine unnumerierte Liste. Die nummerierte Liste hat folgendes Format

  1. Listenelement 1
  2. Listenelement 2
  3. Listenelement 3

Die unnummerierte Liste hat folgendes Format

  • Listenelement A
  • Listenelement B
  • Listenelement C
